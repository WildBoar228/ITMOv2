Ты независимый проверяющий модели угроз.

В директории [lab](./lab/) находится онлайн-магазин на Python.
Необходимо найти в нем все потенциальные уязвимости безопасности.

План работы:
1. найди уязвимости и классифицируй их по STRIDE
2. перечисли уязвимости по категориям (в порядке убывания критичности)
3. запиши отчет о найденных проблемах в безопасности в [REPORT_01.md](./REPORT_01.md)
4. составь план для закрытия дыр, опиши воспроизводимые проверки
5. добавь тесты для проверки безопасности
6. проведи исправления по /skills:test-driven-development
7. напиши отчет об исправлениях в [REPORT_02.md](./REPORT_02.md)

Закончи, когда все найденные уязвимости будут закрыты, покрыты воспроизводимыми тестами и исправлены.
