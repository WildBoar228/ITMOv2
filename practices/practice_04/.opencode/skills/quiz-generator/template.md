# Шаблон вопроса для quiz-generator

Один факт из источника — один такой блок. Скопируй структуру точь-в-точь,
заполни своими данными, затем прогони по чек-листу из SKILL.md.

```json
{
  "id": "q1",
  "q": "Формулировка вопроса (один факт, без подсказки ответа внутри)",
  "options": [
    "Неверный, но правдоподобный вариант",
    "Правильный ответ",
    "Частая ошибка по этой теме",
    "Соседний термин из источника"
  ],
  "correct": 1,
  "explain": "Почему верен именно этот вариант, выжимка из источника (1–2 предложения)."
}
```

Игра целиком:

```json
{
  "id": "deck-<тема-латиницей>",
  "title": "Название игры",
  "questions": ["<блоки вопросов по шаблону выше>"]
}
```

Границы (совпадают с `validateDeck()` в `project/app.js` и `tests/test_decks.py`):

- вопросов ≥ 1, вариантов ровно 4, `correct` — 0–3
- весь текст trim, пустых строк нет
- `explain` опционален; пустая строка = как нет
- `q` ≤ 200 символов, вариант ≤ 120, `explain` ≤ 300 (лимиты полей редактора)
