# Quiz-карточки

Локальная викторина для одного игрока. Стек: **React 19, Vite 8, Material UI (MUI)** и JavaScript. Отдельный сервер API и переменные окружения не нужны.

## Установка и запуск

Нужны Node.js 22.12+ (рекомендуется Node.js 24 LTS) и npm. Из корня репозитория:

```bash
cd practices/practice_08/project
npm ci
npm run dev
```

Откройте адрес, указанный Vite в терминале, обычно http://localhost:5173. Остановка — `Ctrl+C`.

Проверка сборки и её локальный просмотр:

```bash
npm run build
npm run preview
```

Сборка создаётся в `dist/`. `preview` предназначен для локальной проверки сборки.

## Пользовательский сценарий

1. Выберите игру в списке и нажмите «Играть».
2. Отвечайте на вопросы: четыре варианта, 15 секунд на каждый вопрос.
3. После ответа или таймаута увидите обратную связь, правильный вариант и пояснение, если оно задано. За правильный ответ начисляются 10 очков плюс оставшиеся секунды с округлением вверх.
4. Переходите кнопкой «Далее», затем «К результату». На итоговом экране доступны повторное прохождение и возврат к списку.

Можно создавать, редактировать и удалять игры, импортировать JSON и скачивать весь список. Название, текст вопроса и четыре варианта обязательны; правильный ответ выбирается переключателем. Пояснение необязательно.

Исходные игры загружаются из `public/data/decks.json`. Изменения и прогресс остаются в памяти до перезагрузки страницы. Для переноса своих игр скачайте JSON и затем импортируйте его. При импорте повторяющиеся идентификаторы заменяются уникальными; некорректный файл отклоняется с сообщением об ошибке.

## Структура

- `src/main.jsx` — точка входа, тема MUI и базовые стили.
- `src/App.jsx` — навигация, загрузка данных, импорт/экспорт и подтверждение удаления.
- `src/components/DeckList.jsx` — список игр.
- `src/components/DeckEditor.jsx` — форма создания и редактирования.
- `src/components/Game.jsx` — вопросы, таймер и результат.
- `src/decks.js` — формат данных, валидация и общие функции.
- `src/theme.js` — общие цвета, типографика, отступы и настройки компонентов.
- `src/style.css` — сетки, фокус и подсветка ответов.

Переиспользуются компоненты MUI: кнопки, карточки, поля, переключатели, диалог, сообщения и индикаторы загрузки/времени. Сохранена тёмная палитра исходного приложения. [Макет практики](../prototype.html) хранится отдельно; визуальное соответствие ему требует дальнейшей доработки.

## Проверки

Клиентские тесты на этом этапе не добавлены. Команда `npm run build` проверяет сборку приложения, но не заменяет проверки пользовательского поведения.
