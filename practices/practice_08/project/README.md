# Quiz Club

Локальная викторина для одного игрока. Стек: **React 19, Vite 8, shadcn/ui, Tailwind CSS 4**, JavaScript. Отдельный сервер API и переменные окружения не нужны.

## Установка и запуск

Нужны Node.js 22.12+ (рекомендуется Node.js 24 LTS) и npm. Из корня репозитория:

```bash
cd practices/practice_08/project
npm ci
npm run dev
```

Откройте адрес Vite из терминала, обычно http://localhost:5173. Остановка — `Ctrl+C`.

Проверка сборки и локальный просмотр:

```bash
npm run build
npm run preview
```

Сборка создаётся в `dist/`. `preview` предназначен для локальной проверки сборки.

## Библиотека компонентов и макет

Используется [shadcn/ui](https://ui.shadcn.com/): готовые компоненты добавлены официальным CLI в `src/components/ui/`, конфигурация — `components.json` (`new-york`, JavaScript). Их внешний вид адаптирован к [прототипу](../prototype.html) и [скриншотам](../prototype_screenshots/).

| Готовые компоненты | Где используются |
|---|---|
| `Button` | Создание, запуск, ответы, переходы, импорт/экспорт |
| `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter` | Карточки игр и блоки редактора |
| `Badge` | Категория на обложке и в предпросмотре редактора |
| `Input`, `Label`, `Select` | Поля редактора и выбор правильного ответа |
| `Dialog`, `DialogContent`, `DialogHeader`, `DialogTitle`, `DialogDescription` | Редактор, игра и результат |
| `AlertDialog` и его составные компоненты | Подтверждение удаления |
| `Alert`, `AlertTitle`, `AlertDescription` | Ошибки, обратная связь и успешные действия |
| `Progress` | Оставшееся время текущего вопроса |

Переиспользуются реализация и API компонентов, включая поведение диалогов и Select на базе Radix UI. В `Progress` значение также передаётся в корневой primitive для доступного `aria-valuenow`. Визуальные изменения сосредоточены в `src/style.css`: общие токены shadcn/ui, цвета, шрифты, отступы, скругления, обложки и адаптивные сетки. Это не отдельная библиотека, написанная с нуля.

Из макета взяты светлый фон, зелёные кнопки, пастельные обложки, композиция карточек, двухколоночные варианты ответа и модальные окна. Шрифты DM Sans и Manrope поставляются локально через Fontsource; обращения к Google Fonts нет. Язык оболочки — английский, как в макете; исходные русскоязычные вопросы сохранены.

Макет обновлён под реализацию: кнопки правки и удаления, импорт/экспорт, поля оформления и предпросмотр, текущий счёт, выход из игры и полоса оставшегося времени. Кнопка перехода к следующему вопросу заблокирована до ответа или таймаута.

`../prototype.html` — кликабельный экспорт из 15 экранов. Его можно открыть прямо в браузере без сервера: изображения находятся рядом в `../prototype_screenshots/`. Показаны список, обе части редактора, игра, ответ, таймаут, результат, успешное сохранение, удаление, загрузка, пустые данные, ошибка загрузки, ошибка формы и мобильные экраны.

Обновить снимки текущего приложения:

```bash
npx playwright install chromium
npm run prototype:export
```

Экспорт запускает Vite на порту 4175 и закрывает его после съёмки. Для загрузки, пустого списка и ошибки подменяются ответы JSON. Игровые экраны и сохранение используют настоящую логику; таймаут ускоряется браузерными часами. Исходные данные приложения не изменяются.

## Пользовательский сценарий

1. Нажмите **Play quiz** у выбранной игры.
2. Выберите один из четырёх ответов за 15 секунд.
3. После ответа или таймаута увидите правильный вариант и пояснение, если оно задано. За правильный ответ начисляются 10 очков плюс оставшиеся секунды с округлением вверх. Повторное нажатие не меняет результат.
4. Перейдите через **Next question** и **To the result** к итоговым очкам, числу правильных ответов и точности. Можно начать заново или вернуться к списку.

**New game** открывает редактор. Название, хотя бы один вопрос и все четыре варианта обязательны. Правильный ответ выбирается через Select (A–D). Категория, описание, эмодзи обложки и пояснения необязательны. Цвет обложки выбирается через **Cover color**; эмодзи задаётся в **Cover emoji**. Предпросмотр сразу показывает выбранные цвет, эмодзи и категорию. **Save game** добавляет игру в список; правка сохраняет существующий идентификатор и настройки обложки.

Полоса таймера убывает от 100% до 0% за 15 секунд и останавливается после ответа. Последние 5 секунд выделяются цветом. При переходе к следующему вопросу отсчёт и полоса начинаются заново.

Диалоги поддерживают клавиатуру, удерживают фокус внутри и возвращают его к вызвавшей кнопке после закрытия. Для длинных форм доступна прокрутка. На узких экранах карточки и ответы располагаются в одну колонку.

## Данные

Исходные игры загружаются из `public/data/decks.json`. Загрузка, пустой список и ошибка отображаются отдельно; при ошибке доступна повторная попытка.

Изменения и прогресс остаются в памяти до перезагрузки страницы. Для сохранения используйте **Export quizzes**, затем **Import JSON**. Повторяющиеся идентификаторы при импорте заменяются уникальными. Некорректный файл отклоняется с сообщением об ошибке.

Сохранён формат `id`, `title`, `questions` с полями вопроса `id`, `q`, `options`, `correct` (индекс 0–3), необязательным `explain`. Добавлены необязательные строковые поля игры `category`, `description`, `emoji`, `color`. Для старых файлов предусмотрены оформление и подписи по умолчанию. Для цвета используется HEX `#RRGGBB`, иначе применяется пастельный цвет по умолчанию.

## Структура

- `src/main.jsx` — точка входа и локальные шрифты.
- `src/App.jsx` — коллекция, загрузка, диалоги, импорт/экспорт, удаление.
- `src/components/DeckList.jsx` — карточки игр.
- `src/components/DeckEditor.jsx` — форма создания и редактирования.
- `src/components/Game.jsx` — вопросы, таймер и результат.
- `src/components/ui/` — компоненты shadcn/ui.
- `src/decks.js` — валидация, идентификаторы и оформление старых наборов.
- `src/style.css` — общие токены, тема и адаптивные стили.
- `tests/` — браузерные проверки заданий 5–9.
- `playwright.config.js` — Chromium, обычный и узкий экран, запуск production-сборки.
- `scripts/export-prototype.mjs` — обновление экранов макета.

## Проверки

Установка браузера и запуск всех клиентских тестов:

```bash
npm ci
npx playwright install chromium
npm test
```

Playwright автоматически собирает приложение и запускает `vite preview` на порту 4174. Заранее запускать приложение не нужно. Проверяется 21 сценарий в двух конфигурациях: **1280 × 900** и **375 × 812** — всего **42 проверки**. Автоматические повторные запуски отключены.

| Файл | Что проверяется |
|---|---|
| `tests/keyboard.spec.js` | Полный квиз и создание игры только с клавиатуры, сохранение выбранного в Select ответа через прохождение созданной игры, видимый фокус, удержание и возврат фокуса, Escape, подтверждение удаления, доступность кнопок в длинном редакторе |
| `tests/states.spec.js` | Ожидание ответа, пустая коллекция, HTTP-ошибка, повреждённый JSON, неверная схема, повторная загрузка, обязательные поля, пробелы, незаполненный ответ, отсутствие вопросов, исправление формы и повторный импорт |
| `tests/repeated-actions.spec.js` | Двойной клик и повторный Enter при сохранении, повторный импорт во время ожидания, восстановление после ошибки чтения файла, ровно 20 очков после двойного ответа при фиксированном времени, остановка и сброс таймера, таймаут |
| `tests/answers.spec.js` | Неверный ответ, правильный вариант и пояснение, блокировка ответов, результат 0/1 и ноль очков |

В клавиатурных сценариях используются реальные Tab, Shift+Tab, Enter, Space и стрелки без `.click()` или `.focus()`. Проверяется не только наличие фокуса, но и его CSS-индикатор на кнопке запуска, а также нахождение действий в видимой области экрана.

Ответы загрузки подменяются данными того же формата, что `public/data/decks.json`. Сохранение локальное и синхронное, поэтому тесты проверяют отсутствие второй записи. Для асинхронного импорта задерживается `File.text()`: во время ожидания кнопка заблокирована и повторное событие не вызывает второе чтение. Сетевого запроса сохранения в проекте нет. В тестах таймера используется `page.clock`, без реального ожидания 15 секунд.
