# Проверка заданий 5–9

## Запуск

Среда: Linux, Node.js 24.21.0, Chromium из Playwright. Команда из `project/`:

```bash
npm test
```

Результат полного запуска после исправления тестов:

```text
Running 42 tests using 2 workers
42 passed (12.9s)
```

Это 21 сценарий на каждом из двух экранов: desktop (1280 × 900) и narrow (375 × 812). Каждый запуск заново собирает приложение. Повторные попытки не используются.

## Соответствие требованиям

| Требование | Подтверждение |
|---|---|
| Основной сценарий с клавиатуры | Два вопроса → обратная связь → результат 2/2 → возврат к кнопке запуска; только Tab, Enter и Space |
| Подписи полей и клавиатурная форма | Поля находятся по доступным названиям, заполняются с клавиатуры; Select меняется стрелками, сохранённый ответ B подтверждается прохождением новой игры до результата 1/1 |
| Фокус | CSS-outline кнопки, фокус заголовка вопроса, Tab/Shift+Tab внутри диалога, возврат после Escape и удаления |
| Узкий экран | Все сценарии на 375 px; нет горизонтального переполнения, нижние кнопки длинной формы попадают в видимую область при Tab |
| Загрузка, пустые данные, успех, ошибка | Задержанный ответ, пустой массив, успешная коллекция/сохранение, HTTP 503, повреждённый JSON и неправильная схема |
| Исправление и повторная попытка | Повторная загрузка, заполнение обязательных полей, исправление пробелов и пустого ответа без потери данных, повторный импорт |
| Защита от повтора | Одна запись после двойного клика/повторного Enter; одно чтение файла и одна игра при повторном импорте во время ожидания |
| Игровые состояния | При фиксированных 10 оставшихся секундах двойной клик даёт ровно 20 очков; после неверного второго ответа итог остаётся 20 очков и 1/2. Таймер останавливается после ответа, сбрасывается на следующем вопросе, таймаут блокирует ответы |
| Неверный ответ | Показаны ошибка, правильный вариант и пояснение; все ответы заблокированы; итог 0/1, точность 0%, очки 0 |

Сохранение не отправляет запрос: оно синхронно изменяет коллекцию в памяти. Ожидание и исключение второй асинхронной операции проверяются на импорте файла. Начальные данные тестов соответствуют контракту `decks.json`.

## Проверка чувствительности

Временно убрана проверка `importingRef.current` в обработчике импорта. Запущен тест:

```bash
npm test -- --project=desktop --grep 'повторный импорт во время'
```

Тест упал по нужной причине:

```text
Expected: 1
Received: 2
1 failed
```

Вместо одного чтения файла начались два. Проверка восстановлена, затем весь набор запущен на исходном рабочем коде. Это подтверждает, что тест обнаруживает потерю защиты, а не только наличие кнопки или сообщения.

## Проверка AI-результата

В первом варианте AI использовал несуществующий `Locator.isFocused()`. Проверка заменена чтением `document.activeElement` без принудительного перемещения фокуса. В тесте Select добавлено ожидание реального фокуса пункта перед следующей клавишей. Для правильного ответа учтено изменение доступного названия после появления значка «Correct answer». Ожидания не заменены произвольными задержками.

Макет экспортирован командой `npm run prototype:export`: 15 PNG-файлов, связанные через `../prototype.html`. Снимки снимаются после загрузки локальных шрифтов, с завершёнными анимациями; длинный редактор показан двумя состояниями прокрутки.
