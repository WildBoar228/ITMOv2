## Примеры

### Хороший результат
Таблица сценариев включает:
- Error storm: заглушка LLM выдаёт таймауты/ошибки при RPS X, проверяется ответ <=10с и соответствие OUT-1; Evidence: файл отчёта с p50/p95/p99, error rate (4xx/5xx), CPU/RAM.
- Validation under load: смесь корректных и ошибочных запросов; проверяется 100% 413 для diff>20000 и 100% 422 при отсутствии diff; без произвольных latency-порогов.
- Environment: описаны аппаратные ресурсы, воркеры, раннер, профиль заглушки; метрики и артефакты названы явно.

Два сценария с произвольными порогами p95 ≤ 500 мс / 1 с, без описания окружения и без проверки отказных кодов 413/422 под нагрузкой; Evidence: «Отчёт теста» без конкретики.
